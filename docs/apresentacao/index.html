01 — problema

Química em texto, sem coordenadas

A MoleculeDSL separa a intenção química da visualização. Quem escreve declara átomos e ligações; o compilador cuida da estrutura, da posição dos erros e das verificações químicas.

Legível

Programas curtos, próximos da notação usada em aula.

Precisa

Todo diagnóstico aponta fase, código, linha, coluna e uma explicação em português.

Auditável

Dados químicos só entram com fonte registrada no levantamento.

02 — linguagem

Um vocabulário pequeno, casos expressivos

Espécie, átomos, ligações, anéis e configuração, em qualquer ordem dentro da espécie.

Água

species molecule "Water" {
    atom O
    atom H
    atom H

    bond H-O
    bond O-H
}

Ligações

Carga e coordenação

Configuração

03 — pipeline

Cada fase recebe uma entrada mais limpa

Se uma fase falha, as seguintes não rodam: sem erros em cascata, com a origem real do problema preservada.

04 — léxico e sintático

ANTLR 4, sem mensagens opacas

Nenhum texto interno em inglês chega ao usuário: cada erro vira um código estável em português.

O ANTLR entrega

Lexer, parser LL(*), parse tree, visitor e recuperação por inserção, remoção e sincronização.

O projeto personaliza

Listeners em português, IDs LEX/SIN, limite de dez erros por fase e recuperação que não apaga o início do próximo comando.

Erro léxico real

Erro léxico [LEX-001] na linha 4, coluna 4: caractere inválido '@'

Erro sintático real

Erro sintático [SIN-004] na linha 3, coluna 10: esperado '}' para fechar a molécula
05 — AST

A árvore contém conceitos, não pontuação

Dataclasses próprias guardam linha, coluna e quantificadores; a expansão em átomos e ligações individuais só acontece no modelo.

07 — além da validação

O grafo validado vira química

Com a análise sem erros, o compilador resolve fórmulas e gera relatórios. Saídas reais, pré-computadas.

Solver de estruturas

Geração ordenada de Read-Faradzev: cada isômero sai uma vez, sem guardar chaves.

C6H6       217 (esperado 217)    0.08s

Estereoquímica

Contagem exata pelo grupo de automorfismos, com formas meso descontadas.

Estereoisômeros desta constituição: 3 (1 aquiral(is), 1 par(es) de enantiômeros)
Estereoisômero declarado: aquiral (forma meso)

Tautômeros

Tautômeros: 2 estrutura(s), a declarada primeiro
  Tautômero 1: forma declarada
  Tautômero 2: H#1 em O#1; ligações c1 (C#1)=c2 (C#2), c2 (C#2)-O#1

Aromaticidade

Aromaticidade (1 sistema(s) cíclico(s))
  [n (N#1) c1 (C#1) c2 (C#2) c3 (C#3) c4 (C#4)] 6 elétron(s) pi, aromático (Hückel)

10 — limites e futuro

O que não foi fingido como resolvido

Octeto

OCT-001 foi removida: as regras de valência já cobrem os elementos com dados.

Ligação metálica

METAL-002 lembra que uma aresta não valida o sólido metálico.

Fontes antes de regras

Valências sem fonte (Be, Al, Si, metais de transição) não entram no código.

Solver

Até 12 átomos pesados, com JSON/JSONL, timeout e busca isolada.

Geometria 3D

O desenho 3D do playground é ilustrativo; quiralidade planar e barreiras de rotação ficam fora.

Isótopos

Sem isótopos na linguagem, a regra CIP 2 nunca tem empate a resolver.

uso

Do clone à molécula analisada

Requisitos: Python 3.10+, Java (para gerar o parser) e o pacote antlr4-tools.

1. Instalar

python3 -m pip install -r requirements.txt
python3 -m pip install -r requirements-solver.txt  # opcional: CP-SAT

2. Gerar o parser

sh gerar.sh

Cria a pasta gerado/ com lexer, parser e visitor do ANTLR.

3. Compilar uma molécula

python3 src/main.py exemplos/agua.mol
python3 src/main.py --tokens --ast --modelo exemplos/agua.mol
python3 src/main.py --estereo exemplos/acido_tartarico_meso.mol

4. Rodar os testes

python3 testar.py
python3 tests/benchmark_solver.py --backend=ambos

Opções de linha de comando

Texto real de python3 src/main.py sem argumentos:

Uso: python src/main.py [--tokens] [--ast] [--modelo] [--resolver|--resolver-todas] <arquivo>
  --tokens  mostra os tokens reconhecidos
  --ast     mostra a AST construída
  --modelo  mostra o modelo da molécula (átomos e ligações)
  --resolver infere ligações quando a entrada contém somente átomos
  --resolver-todas enumera até 10 estruturas não equivalentes
  --max-solucoes=N define o limite da enumeração
  --tempo-limite=S interrompe a busca após S segundos
  --formato=texto|json|jsonl escolhe a saída do solver
  --backend=reference|cpsat escolhe o backend
  --isolar roda a busca num processo separado
  --eletronico mostra pares livres e elétrons pi de cada átomo
  --ressonancia lista as formas de ressonância
  --tautomeros lista os tautômeros por deslocamento de H
  --aromaticidade aplica a regra de Hückel aos ciclos
  --estereo lista centros e ligações estereogênicas
  --coordenacao descreve metais, ligantes e estados de oxidação
  --aneis=N mantém só estruturas com N anéis
  --ligacoes-multiplas=N mantém só estruturas com N ligações duplas ou triplas
  --exigir=C=O mantém só estruturas com essa cadeia, como O-C=O (pode repetir)
  --proibir=C#C descarta estruturas com essa cadeia (pode repetir)

Comandos

Um arquivo contém uma única espécie. Dentro dela, atom, bond, ring e stereo aparecem em qualquer ordem.

Cabeçalho

species <tipo> "Nome" [charge +N|-N] [unpaired N] { … }
// tipos: molecule, molecular_ion (exige charge), ionic_solid,
//        covalent_network, metallic_solid
// legado: molecule "Nome" { … }

atom

[Nx] atom Elemento[(±carga)] [as nome]
atom O
atom N(+1) as n1
4x atom H as h      // cria h1, h2, h3, h4

bond

bond ref operador ref [xN]
bond H-O
bond C-H x4         // repete com os próximos H livres
bond N->B            // coordenada: doador -> receptor

ring

ring c1 c2 c3 c4 c5 c6  // pelo menos três nomes, na ordem do ciclo

Referências e nomes

Uma referência é um símbolo de elemento (H) ou um nome de átomo (c1).

  • Pelo símbolo, a ligação usa o próximo átomo daquele elemento ainda não citado. Com um só átomo do elemento, é sempre ele.
  • Com 4x atom H as h, o nome vira prefixo: h1 a h4.
  • Nomes começam com letra minúscula. Palavras-chave e nomes como x4 são reservados.
  • Em stereo, a referência precisa identificar um único átomo.

Palavras reservadas

molecule species molecular_ion ionic_solid covalent_network metallic_solid
charge unpaired atom bond as ring stereo

Configuração (stereo)

stereo c2 R          // centro: R ou S; r ou s se pseudoassimétrico
stereo c2=c3 Z       // ligação dupla: E ou Z
stereo c3 Ra         // aleno, pelo átomo central
stereo a1-b1 Ra      // eixo de biarila (aviso STEREO-005)
stereo r1 r2 trans   // configuração relativa num anel

A semântica confere se o elemento é estereogênico nesta constituição e nas demais configurações declaradas. Com tudo declarado, --estereo diz se o estereoisômero é quiral, aquiral ou meso e mostra o enantiômero.

CódigoSituação
STEREO-001não é elemento estereogênico, ou referência ambígua
STEREO-002descritor não combina com o elemento
STEREO-003descritor repetido
STEREO-004r/s sem a configuração dos ramos
STEREO-005eixo de biarila sem verificação da barreira (aviso)

Gramática ANTLR

Conteúdo real de gramatica/MoleculeDSL.g4:

grammar MoleculeDSL;

// ---------- PARSER ----------

programa
    : molecula EOF
    ;

molecula
    : cabecalho desemparelhados? ABRE_CHAVE comando* FECHA_CHAVE
    ;

cabecalho
    : MOLECULE TEXTO
    | SPECIES MOLECULE TEXTO
    | SPECIES MOLECULAR_ION TEXTO cargaEspecie
    | SPECIES IONIC_SOLID TEXTO
    | SPECIES COVALENT_NETWORK TEXTO
    | SPECIES METALLIC_SOLID TEXTO
    ;

cargaEspecie
    : CHARGE sinal INTEIRO
    ;

desemparelhados
    : UNPAIRED INTEIRO
    ;

comando
    : atomo
    | ligacao
    | anel
    | estereo
    ;

// Ex.: atom O, 4x atom H, atom N(+1), atom C as c1
atomo
    : MULTIPLICADOR_ATOMO? ATOM IDENT carga? (AS NOME)?
    ;

// O sinal negativo reaproveita o token LIGACAO
carga
    : ABRE_PAREN sinal INTEIRO FECHA_PAREN
    ;

sinal
    : MAIS
    | LIGACAO
    ;

// Ex.: bond H-O, bond C-H x4, bond c1=c2, bond N->B
ligacao
    : BOND referencia operador referencia REPETICAO_LIGACAO?
    ;

// Símbolo de elemento ou nome de átomo
referencia
    : IDENT
    | NOME
    ;

operador
    : LIGACAO
    | DUPLA
    | TRIPLA
    | COORDENADA
    | METALICA
    ;

// Um anel precisa de pelo menos três átomos
anel
    : RING NOME NOME NOME+
    ;

// Configuração: stereo c2 R, stereo c2=c3 Z, stereo c2 Sa (aleno, pelo
// átomo central), stereo c1-c7 Ra (eixo de biarila), stereo c1 c4 trans
estereo
    : STEREO referencia (operador? referencia)? descritor
    ;

// R, S, E, Z, Ra, Sa são IDENT; r, s, cis, trans são NOME
descritor
    : IDENT
    | NOME
    ;

// ---------- LEXER ----------

// Palavras-chave (antes de NOME, para vencer no empate)
MOLECULE : 'molecule' ;
SPECIES  : 'species' ;
MOLECULAR_ION    : 'molecular_ion' ;
IONIC_SOLID      : 'ionic_solid' ;
COVALENT_NETWORK : 'covalent_network' ;
METALLIC_SOLID   : 'metallic_solid' ;
CHARGE    : 'charge' ;
UNPAIRED  : 'unpaired' ;
ATOM     : 'atom' ;
BOND     : 'bond' ;
AS       : 'as' ;
RING     : 'ring' ;
STEREO   : 'stereo' ;

// Quantificadores
MULTIPLICADOR_ATOMO
    : [0-9]+ 'x'
    ;

// Antes de NOME: x4 é sempre repetição
REPETICAO_LIGACAO
    : 'x' [0-9]+
    ;

// Números
REAL
    : [0-9]+ '.' [0-9]+
    ;

INTEIRO
    : [0-9]+
    ;

// Texto
TEXTO
    : '"' ~["\r\n]* '"'
    ;

// Identificadores de elementos
IDENT
    : [A-Z] [a-z]?
    ;

// Nomes de átomos
NOME
    : [a-z] [a-z0-9_]*
    ;

// Operadores de ligação (-> vence - por maior casamento)
COORDENADA : '->' ;
LIGACAO    : '-' ;
DUPLA      : '=' ;
TRIPLA     : '#' ;
METALICA   : '~' ;

// Sinal de carga e delimitadores
MAIS        : '+' ;
ABRE_PAREN  : '(' ;
FECHA_PAREN : ')' ;
ABRE_CHAVE  : '{' ;
FECHA_CHAVE : '}' ;

// Comentários
COMENTARIO
    : '//' ~[\r\n]* -> skip
    ;

// Espaços em branco
ESPACO
    : [ \t\r\n]+ -> skip
    ;
